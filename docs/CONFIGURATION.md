# CalSpread Backend — Configuration Manifest

Every meaningful environment variable, generated by inspecting the source. This is a
**reference for the Go rewrite and for operators**, not a refactor — `process.env` access
is left where it is.

Conventions:
- **Secret?** ✅ means never log the value and never return it to the browser.
- **Default** is the shipped fallback; blank means "unset disables the feature".
- Types: `string`, `int` (ms/count), `float` (percent/ratio), `bool`
  (`1/true/yes` vs `0/false/no`), `url`.

> ## ⚠️ Variables that can enable REAL live trading
> Getting any of these wrong can send real orders to a broker. Treat with the most care.
>
> | Variable | Effect |
> |---|---|
> | `BOX_EXECUTION_MODE=live` | switches the Box engine from paper to **live order placement**. Invalid unless `BOX_LIVE_TRADING_ENABLED=true` — the engine refuses to start live otherwise (`src/box/config.ts`). |
> | `BOX_LIVE_TRADING_ENABLED=true` | the deployment kill switch that *permits* live mode. False by default. |
> | `DHAN_LIVE_TRADING_ENABLED=true` | permits real Dhan order placement; live Dhan execution fails closed without it. |
> | `DHAN_STATIC_PUBLIC_IP` / `DHAN_STATIC_IP_EXPECTED` | the static-IP guard; live Dhan startup fails closed if the running host's IP does not match. |
> | `ADMIN_SECRET`, `TOKEN_ROUTE_SECRET`, `INTERNAL_TOKEN_SECRET`, `DHAN_API_SECRET`, `KITE_API_SECRET` | credentials whose leak grants order placement. |
>
> Paper-safe default posture: `BOX_EXECUTION_MODE=paper_latency`,
> `BOX_LIVE_TRADING_ENABLED=false`, `DHAN_LIVE_TRADING_ENABLED=false`.

## Box execution

Mode: `BOX_EXECUTION_MODE` (`paper_touch`/`paper_latency`/`paper_legging`/`live`),
`BOX_LEG_EXECUTION_MODE`. Paper modelling: `BOX_SIMULATED_LATENCY_MS`,
`BOX_SIMULATED_DECISION_MS`, `BOX_LEG_TIMEOUT_MS`, `BOX_LEG_MAX_CHASE_TICKS`,
`BOX_LEG_UNWIND_LATENCY_MS`, `BOX_UNWIND_MAX_CHASE_TICKS`, `BOX_MAX_CONCURRENT_EXECUTIONS`.

Paper live-parity profile (default OFF; layered on `paper_legging`, never changes
`standard`): `BOX_PAPER_EXECUTION_PROFILE` (`standard`|`live_parity`),
`BOX_PAPER_MAX_CONCURRENT_EXECUTIONS` (default = `BOX_LIVE_MAX_CONCURRENT_EXECUTIONS`),
`BOX_PAPER_LATENCY_MODE` (`constant`|`recorded_samples`), `BOX_PAPER_LATENCY_SAMPLES`
(observed POST→ACK ms), `BOX_PAPER_LATENCY_ACK_TERMINAL_SAMPLES` (observed ACK→terminal
ms), `BOX_PAPER_LATENCY_SEED`. Under `live_parity` the four legs are scheduled through the
same priority queue + concurrency cap + `BOX_LIVE_BROKER_MIN_INTERVAL_MS` pacing as live.

Execution timing observability / latency calibration (fail-open, off the trading hot path):
`BOX_EXECUTION_TIMING_METRICS_ENABLED` (default `true`), `BOX_EXECUTION_TIMING_WINDOW`
(default `500`), `BOX_DEPLOYMENT_REGION` / `BOX_EXECUTION_CALIBRATION_REGION` (region label
stamped on calibration datasets; never auto-detected). See `src/box/LIVE_EXECUTION.md` for
the recommended validation profile and calibration status.

Live-only limits (all under the `BOX_LIVE_*` prefix — order pacing, timeouts, and the
risk caps below).

## Box charges

`BOX_BROKERAGE_PER_ORDER`, `BOX_BROKERAGE_MAX_PCT`, `BOX_STT_SELL_PCT`,
`BOX_STT_ROUND_NEAREST_RUPEE`, `BOX_STT_TYPE`, `BOX_EXCHANGE_TXN_PCT`,

> **Rate accuracy is P&L accuracy.** `BOX_STT_SELL_PCT` is the single largest cost in a
> round trip; an understated value flatters every paper result. The shipped default
> reflects the 1 Apr 2026 options-STT revision — verify against your account.
