## Recovering reference tooling

Inspect files without changing the current checkout, for example:

```bash
git show 8de7ca5:internal/fairvalue/testdata/gen_model.mjs
git show 1ea1d958ebf5c4a0fc673d786f5ee9638bdffa8d:src/fairValue/pipeline.ts
```

For deliberate regeneration, use a separate scratch checkout of `8de7ca5` and the
generator-specific tool/dependency notes in the historical stage reports. Preserve
the reference inputs, compare output to current digests and explicitly review any
difference. Historical setup/reports mention Node/MongoDB/Redis/Box because they record
the reference implementation; those systems are not dependencies of the Go runtime.
The dotenv golden intentionally includes the historical example environment as parser
fixture data, not active database configuration.
