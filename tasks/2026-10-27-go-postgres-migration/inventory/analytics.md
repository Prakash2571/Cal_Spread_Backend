## 0. Conventions and cross-cutting JS→Go traps (apply to every unit below)

0.1 Verified numeric probes on Node v22.22.1 (reproduce with `node -e`):
- `x ** 2 === x * x` for 2,000,000 random x → exactly `x*x` (safe to use `x*x` in Go).
- `x ** 3 !== x*x*x` for 27.6 % of random x; and V8's `x ** 3` itself differs from the correctly-rounded cube for 9.9 % of x.
  So V8 `pow` is its own fdlibm/libm-class algorithm; **Go `math.Pow(x,3)` (repeated squaring) will not be bit-identical**.
  The only place `** 3` is used is `svi.ts:15` (`root ** 3`, SVI second derivative `g`), so the effect is ≤1 ulp in a diagnostic.
- `Math.hypot(a,b)` for 2 finite args is bit-identical (2,000,000 samples) to V8's Kahan algorithm:
  `m=max(|a|,|b|); if m==0 →0; sum=0,c=0; for v in (a,b){ n=|v|/m; s=n*n-c; p=sum+s; c=(p-sum)-s; sum=p }; return sqrt(sum)*m`
  (Inf arg → +Inf even with NaN; any NaN otherwise → NaN). It differs from naive `sqrt(a*a+b*b)` in 37 % of samples and Go's
  `math.Hypot` uses a different algorithm → **port the Kahan routine, do not call `math.Hypot`**. Used in `svi.ts:4,13` (`sviVariance`, `sviDerivatives`).
- `Math.round(x)` = `floor(x + 0.5)` semantics: `Math.round(2.5)=3`, `Math.round(-2.5)=-2`, `Math.round(-0.4)=-0`,
  `Math.round(0.49999999999999994)=0`. Go `math.Round` rounds half **away from zero** (`-2.5 → -3`) → use `math.Floor(x+0.5)` **but**
  `x+0.5` double-rounding is what V8 avoids (V8 returns 0 for 0.49999999999999994); implement as
  `r:=math.Floor(x); if x-r >= 0.5 {r++}` and preserve `-0`.
- `Number.prototype.toFixed`: ties use the exact binary value, then "pick larger n": `(0.5).toFixed(0)="1"`, `(2.5).toFixed(0)="3"`,
  `(-2.5).toFixed(0)="-3"` (sign handled separately), `(0.125).toFixed(2)="0.13"`, `(1.005).toFixed(2)="1.00"`, `(10.235).toFixed(2)="10.23"`.
  Go `strconv.FormatFloat(x,'f',n,64)` rounds the exact binary value half-to-even on exact ties (`0.125 → "0.12"`, `2.5 → "2"`). Differs only on **exactly representable ties** (x·10ⁿ has fractional part exactly .5) → handle explicitly.
- `String(number)` / template literal / `JSON.stringify(number)`: shortest round-trip digits; fixed notation iff `1e-6 <= |x| < 1e21`,
  else exponent form with unpadded signed exponent (`1e-7`, `1.5e-7`, `1e+21`). `String(-0)="0"`. Go's `encoding/json` uses the same
  1e-6/1e21 switch and e-notation cleanup, but encodes `-0` as `-0` (JS: `0`) and **errors on NaN/±Inf** (JS: `null`).
  Reason strings that interpolate numbers (e.g. `iv.ts:49` "Premium outside European bounds [lo, hi]") need a JS-compatible formatter.
- `JSON.stringify`: `NaN/±Infinity → null`, `-0 → 0`, `undefined` object members are **omitted**, `undefined` array items → `null`, key order = insertion order. Go must
  (a) map non-finite floats to `null`, (b) normalise `-0` to `0`, (c) use pointer/omitempty types for "omitted if undefined", (d) disable HTML escaping (`SetEscapeHTML(false)`).
- FMA fusion: Go may fuse `x*y+z` into FMA on arm64/ppc64/s390x (and amd64 with GOAMD64=v3). All Horner loops (`normal.ts`), `(1-alpha)*a+alpha*b`, and
  `sum += w*r*r` accumulations are non-fused in JS. In Go wrap products in `float64(x*y)` to forbid fusion.
- libm: V8 `Math.exp/log/sqrt/sin/...` use bundled fdlibm ports (`base::ieee754`); `sqrt` is correctly rounded everywhere. Go's `math.Exp` has assembly on amd64/arm64/s390x
  with different rounding; `math.Log` is a pure-Go fdlibm port (matches V8 `log` algorithmically). For ulp-level parity port V8's `ieee754::exp` into Go or accept tolerance-based golden checks (see §9 for tolerances).
- `Number.EPSILON = 2^-52 = 2.220446049250313e-16`. `Math.SQRT2=1.4142135623730951`, `Math.SQRT1_2=0.7071067811865476`, `Math.PI=3.141592653589793`.
- `Math.max()`/`Math.min()` with zero args → `-Infinity`/`+Infinity`; with any NaN → NaN. Spread `Math.min(...arr)` over >~120k elements throws RangeError (not reachable here).
- Sorting: `Array.prototype.sort` is **stable** (V8 ≥ 7.0). All comparators below are numeric `a-b` (NaN comparators are undefined behaviour; inputs are filtered finite). Go must use `sort.SliceStable`.
- Map/Set iterate in insertion order (never numeric order). `new Set(numbers)` dedupes by SameValueZero: `+0`/`-0` same, `NaN` equals `NaN`, otherwise exact double equality (no epsilon).
- Dates: `Date.parse("YYYY-MM-DD")` = UTC midnight; `Date.parse("YYYY-MM-DDTHH:mm:ss")` (no offset) = **local server time** (the dev box is IST; production TZ unknown/unset). The Fair Value code only accepts offset-bearing timestamps via `utcTimestamp`, so it is TZ-independent; other modules (captures, index.ts) must be checked per unit.
- `performance.now()` (fractional ms, monotonic) feeds `duration_ms` fields → non-deterministic; strip from golden comparisons.

## A2. `black.ts` (125 lines) — Black-76, bounds, payoff, frozen Greeks
Constants: `YEAR_MS = 365*24*60*60*1000 = 31_536_000_000`; `DAY_COUNT = "ACT/365F: exact UTC seconds / (365 × 24 × 60 × 60)"` (note the `×` U+00D7 characters, emitted in the surface JSON `day_count`).
- `yearFraction(expiry: string|number, valuation: string|number): number` — numbers are epoch ms (no validation beyond finite); strings go through `utcTimestamp()` (§A11) then `Date.parse`; either non-finite → `throw Error("Invalid UTC valuation/expiry timestamp.")`. Returns `(e - v)/YEAR_MS` (can be ≤0 or negative).
- `validateBlackInput({f,k,d,w,side})`: throws `"Black requires finite F>0, K>0, D>0 and total variance w>=0."` unless all finite and `f>0,k>0,d>0,w>=0`; throws `"Unsupported option side/style; European CE/PE only."` if side ∉ {CE,PE}; throws `"Discounted notional exceeds numeric range."` if `!isFinite(d*max(f,k))`.
- `priceBounds(f,k,d,side)` → validates with `w:0`; CE `{lower: d*max(f-k,0), upper: d*f}`; PE `{lower: d*max(k-f,0), upper: d*k}`.
- `blackPrice(input)` (the core; order of operations is the contract):
  1. `validateBlackInput`.
  2. `w===0` → `d*max(side==CE ? f-k : k-f, 0)`.
  3. `root=sqrt(w)`; `lm = ln(k) - ln(f)` (two separate logs, then subtract); `d1 = -lm/root + 0.5*root` (`(-lm)/root + (0.5*root)`); `d2 = d1 - root`.
  4. `lm === 0` (exact equality of the two logs, not `k===f`) → return `d*f*erf(root/(2*SQRT2))` for **both** CE and PE (`(d*f)*erf(...)`; `2*SQRT2 = 2.8284271247461903`).
  5. `f<=k`: `call = d*k*max(0, (f/k)*N(d1) - N(d2))` (`(d*k)*max`), `put = call + d*(k-f)`.
     else: `put = d*f*max(0, (k/f)*N(-d2) - N(-d1))`, `call = put + d*(f-k)`. Return CE→call, PE→put. `N` = `normalCdf`.
- `blackFromIv(f,k,t,d,iv,side)`: throws `"IV pricing requires T>0 and finite decimal IV>=0; use settlementPayoff at expiry."` if `!isFinite(t)||t<=0||!isFinite(iv)||iv<0`; else `blackPrice({f,k,d,w: iv*iv*t, side})` (`(iv*iv)*t`).
- `settlementPayoff({strike,side,lot,settlement,indicative,settlementUnderlying}) → ExpiryPayoff {value, value_per_lot, status, reason}` (JSON key order):
  throws `"Invalid expiry contract inputs."` unless `isFinite(strike)&&strike>0 && Number.isSafeInteger(lot)&&lot>0 && side∈{CE,PE}`; throws `"Invalid settlement underlying."` if `settlement` or `indicative` non-null and (non-finite or `<0`). `u = settlement ?? indicative` (note `??`: `0` is a valid settlement). `value = u===null ? null : max(CE? u-strike : strike-u, 0)`; `value_per_lot = value===null ? null : lot*value`.
  `status`: settlement!==null→`"final_settlement"`; else indicative!==null→`"indicative_payoff"`; else `"settlement_unknown"`. `reason`: `Final payoff using verified ${settlementUnderlying}.` / `Indicative payoff only; official ${settlementUnderlying} is unknown.` / `Official ${settlementUnderlying} and an indicative underlying are unavailable.`
- `frozenBlackGreeks({f,k,d,w,side,t,spot,proportionalCarry}) → BlackGreeks`:
  validates Black input (same throws), `t` finite>0 else `"Greeks unavailable for expired contracts."`, `spot` null or finite>0 else `"Invalid spot for Greeks."`. `value=blackPrice(args)`; `r = -ln(d)/t`.
  `convention` (verbatim string, concatenation, single spaces): `"Frozen-volatility Black; forward delta/gamma; vega per 1 IV percentage point; theta per calendar day at fixed F, r, IV (ACT/365F); rho per 1 rate percentage point at fixed F. Spot transforms require proportional carry and do not move the surface."`
  - `w===0` branch: `callDelta = d*(f>k?1 : f<k?0 : 0.5)`; `delta = CE? callDelta : callDelta - d`; `forward_gamma = f===k ? null : 0`; `vega_1pct = f===k ? d*f*normalPdf(0)*sqrt(t)/100 : 0`; `spot_delta = (proportionalCarry && spot!==null) ? delta*f/spot : null`; `spot_gamma = (proportionalCarry && spot!==null && f!==k) ? 0 : null`; `theta_calendar_day = f===k ? null : r*value/365`; `rho_1pct = -t*value/100`.
  - `w>0`: `root=sqrt(w)`; `d1 = (ln f - ln k)/root + root/2`; `density=normalPdf(d1)`; `delta = d*(N(d1) - (PE?1:0))`; `gamma = d*density/(f*root)`; `iv=sqrt(w/t)`;
    `vega_1pct = d*f*density*sqrt(t)/100`; `spot_delta = delta*f/spot` (if carry&&spot); `spot_gamma = gamma*(f/spot)**2` (= `gamma*((f/spot)*(f/spot))`); `theta_calendar_day = (r*value - d*f*density*iv/(2*sqrt(t)))/365`; `rho_1pct = -t*value/100`.
  JSON order: `forward_delta, forward_gamma, vega_1pct, spot_delta, spot_gamma, theta_calendar_day, rho_1pct, convention`.
- Edge: for `w>0` and `f===k`, `ln f - ln k = 0` → `d1 = root/2` (no special branch, unlike `blackPrice`'s erf path).

## A3. `iv.ts` (80 lines) — implied-vol inversion (bisection with maintained bracket)
`DEFAULT_IV_CONFIG` (verbatim): `{initial_high:0.5, max_volatility:5, max_expansions:8, max_iterations:120, price_tolerance:1e-9, tick_tolerance_fraction:0.01, volatility_tolerance:1e-9, low_vega_threshold:1e-6, max_iv_uncertainty:0.10}` (JSON key order as listed).
`invertIv({f,k,t,d,price,side,tick,uncertainty?,config?}) → IvResult`; result is built by `result(status, reason, iv=null, iterations=0, residual=null, vega=null)` ⇒ **JSON key order `status, reason, iv, iterations, residual, vega`**. Never throws (all failures are statuses).
Algorithm, in order:
1. `invalid_input` ("Finite positive F, K, D, tick and nonnegative premium are required.") if any of `[f,k,t,d,price,tick]` non-finite, or `f<=0||k<=0||d<=0||price<0||tick<=0`, side∉{CE,PE}, `!isFinite(f*d)`, `!isFinite(k*d)`, or `uncertainty!==undefined && (!isFinite||<0)` (`null` uncertainty → `isFinite(null)` false (Number.isFinite(null) is false) ⇒ invalid; callers pass `undefined` or a number).
2. `t<=0` → `expired` ("Expired contract: use its settlement underlying, not implied volatility.").
3. `!isFinite(t*maxVol*maxVol)` → `invalid_input` ("IV total variance exceeds numeric range.").
4. Config sanity: any config value non-finite or `<0`, or `initial_high<=0`, `max_volatility<=0`, `max_iterations<1`, `volatility_tolerance<=0` → `invalid_input` ("Invalid IV solver configuration.").
5. `bounds=priceBounds(f,k,d,side)`; `tolerance = max(price_tolerance, tick*tick_tolerance_fraction, 32*EPSILON*bounds.upper)`.
6. `price < lower - tol || price > upper + tol` → `outside_bounds`, reason `` `Premium outside European bounds [${lower}, ${upper}].` `` (JS number formatting).
7. `price <= lower + tol` → `zero_volatility`, reason "Premium at the tick-aware lower bound; IV is zero/undetermined below tick resolution.", `iv:0, iterations:0, residual: lower - price, vega:0`.
8. `price >= upper - tol` → `no_finite_solution` ("Premium at the upper bound has no finite-volatility solution.").
9. Bracket: `low=0`, `high=min(initial_high, max_volatility)`, `highError = blackFromIv(high)-price`; `while (highError<0 && high<max_volatility && expansions<max_expansions) { high=min(high*2,max_vol); highError=…; expansions++ }`; `highError<0` → `bracket_failure` (`` `No root bracket within maximum decimal IV ${max_volatility}.` ``).
10. Bisection `for iteration=1..max_iterations`: `iv=(low+high)/2`; `error = blackFromIv(iv) - price`;
    **converged iff `(high-low) <= volatility_tolerance && |error| <= max(tolerance, price_tolerance)`** (bracket width evaluated *before* shrinking with this `iv`) → `finish(iv, iteration, error)`; else `error>0 ? high=iv : low=iv` (error exactly 0 → `low=iv`).
    Exhausted → `iteration_failure` ("IV inversion exceeded its iteration budget."), `iv:null, iterations:max_iterations`.
11. `finish`: `root=iv*sqrt(t)`; `d1=(ln f - ln k)/root + root/2`; `vega=d*f*normalPdf(d1)*sqrt(t)` (`((d*f)*pdf)*sqrt(t)`); `unc = max(uncertainty ?? tolerance, tolerance)`; `ill = vega < low_vega_threshold || unc/vega > max_iv_uncertainty`; status `low_vega` (reason "Computed IV is ill-conditioned: quote/tick uncertainty is large relative to vega.") else `valid` ("Bracketed IV inversion converged."); `iterations=iteration`, `residual=error` (signed, model−market), `vega`.
- Determinism: pure, no randomness. A converged bisection returns the *midpoint of the last bracket*; all 120 iterations are available, so at default tolerances convergence needs ~30 iterations (bracket 0.5→1e-9).
- Tests: `pricing.test.mjs`, `hardening.test.mjs`.

## A4. `svi.ts` (73 lines) — raw SVI + diagnostics
`SviParameters {a,b,rho,m,eta}` (JSON order a,b,rho,m,eta; `eta` is the SVI "sigma").
- `sviVariance(p,k) = a + b*(rho*x + hypot(x,eta))`, `x=k-m` (use Kahan `hypot`, §0.1).
- `sviDerivatives(p,k)`: `x=k-m; root=hypot(x,eta); w=sviVariance(p,k); first=b*(rho + x/root); second = b*eta*eta/root**3` (`((b*eta)*eta)/pow(root,3)`);
  `g = w>0 ? (1 - k*first/(2*w))**2 - first*first/4*(1/w + 1/4) + second/2 : null` — precedence: `(1 - (k*first)/(2*w))²  −  (((first*first)/4)*(1/w + 0.25))  +  second/2`. Returns `{w, first, second, g}`.
- `basicSviConstraints(p)`: `Object.values(p).every(Number.isFinite) && b>=0 && |rho|<1 && eta>0 && a + b*eta*sqrt(1-rho**2) >= 0` (`rho**2 = rho*rho`; `((b*eta)*sqrt(...))`).
- `diagnoseSvi(p, observedK, config)` → `{valid, diagnostics, butterfly{min_g,checked_points,domain,right_wing_slope,left_wing_slope,tail_condition,global_proof:false}}`:
  - Diagnostics (errors): `svi_parameter_constraints` ("Raw SVI nonnegative-variance parameter constraints failed.") if !basic; `right=b*(1+rho)`, `left=b*(1-rho)`, `tail = right<2 && left<2`; `right>max_wing_slope||left>max_wing_slope||!tail` → `svi_wing_tail_violation` ("SVI wing slopes exceed configured Lee bound (<2), or the right tail condition fails.").
  - Domain: `low = min(-2, ...observedK) - strike_extrapolation_k`; `high = max(2, ...observedK) + strike_extrapolation_k`.
  - Seeds (a `Set`, insertion order irrelevant because sorted): all `observedK`, `0`, `m`, `m - rho*eta/sqrt(1-rho**2)`, plus `diagnostic_points` uniform points `low + (high-low)*i/(diagnostic_points-1)`, `i=0..diagnostic_points-1`. Filter finite and `low<=k<=high`, sort ascending numerically, `sample` each (memoised in a `Map<number,{g,w}>` keyed by exact double; `minimum` tracks the smallest non-null `g` and `worstK` its first argmin — strict `<`, so the *first encountered* minimiser wins; encounter order = sorted seeds, then refinement order).
  - Refinement: for each adjacent sorted pair `refine(a,b,0)`: stop if `values.size >= 8192`; sample `a`,`b`,`mid=(a+b)/2`; stop if `depth>=adaptive_depth` or any `g===null`; recurse into both halves iff `depth===0 || min(ga,gb,gm) < 0.1 || |gm-(ga+gb)/2| > 0.005` (depth-first, left half first). **The 8192 cap is checked only at entry**, so the map can exceed 8192 by up to a few samples; `checked_points = values.size`.
  - Post: if any sample has `!isFinite(w) || w<=0 || g===null || !isFinite(g)` → error `svi_nonpositive_variance` ("Nonpositive/nonfinite variance or density diagnostic on the adaptive domain."); `minimum < -butterfly_tolerance` → error `butterfly_density_violation` ("Negative g(k) on the adaptive diagnostic domain; SVI valuation suppressed.", `k:worstK`, `value:minimum`); always append info `finite_grid_not_global_proof` ("SVI parameter/wing/tail checks and adaptive finite-domain g(k) tests are numerical diagnostics, not a global arbitrage proof.").
  - `valid = no diagnostic with severity "error"`. `min_g = isFinite(minimum) ? minimum : null`. `domain=[low,high]`, `right_wing_slope=right`, `left_wing_slope=left`, `tail_condition=tail`.
- Tests: `svi.test.mjs`.

## A5. `optimizer.ts` (53 lines) — bounded deterministic Nelder–Mead
`boundedNelderMead({objective,start,bounds,steps,maxIterations,tolerance}) → {point,value,iterations,converged}`. No randomness.
- `clamp(point)[i] = max(lo_i, min(hi_i, v))`. `evaluate(p)`: clip, `v=objective(clipped)`, non-finite → `1e100`; returns `{point: clipped, value}`.
- Initial simplex: `simplex[0]=evaluate(start)`; for `i=0..n-1`: `p=start.slice(); step=steps[i]; p[i] = p[i] + (p[i]+step <= bounds[i][1] ? step : -step)`; push `evaluate(p)` (so the simplex has n+1 points, each *clipped*).
- Loop `iteration=0..maxIterations-1`:
  1. `simplex.sort((a,b)=>a.value-b.value)` (stable; values finite because of the 1e100 floor; ties keep prior order). `best=simplex[0]`, `worst=simplex[n]`.
  2. `valueRange = worst.value - best.value`; `diameter = max over points 1..n of max over dims |p_i - best_i|` (inf-norm).
  3. **Converged iff `iteration >= 40 && valueRange <= tolerance*max(1,|best.value|) && diameter <= 0.025`** → return `{best.point,best.value,iterations: iteration, converged:true}`.
  4. `centroid[i] = (Σ_{s=0..n-1} simplex[s].point[i]) / n` (sum in index order, excludes worst).
  5. `reflected = evaluate(centroid + (centroid - worst))` (coefficient 1).
  6. If `reflected.value < best.value`: `expanded = evaluate(centroid + 2*(reflected.point - centroid))` (uses the *clipped* reflected point); `simplex[n] = expanded.value < reflected.value ? expanded : reflected`.
     Else if `reflected.value < simplex[n-1].value` → `simplex[n]=reflected`.

## D1. Time, session and error helpers
### D1.1 `requireMarketData(res, what)` (:173-182)
`health = brokerManager.activeHealth()`; `health.data_ready` truthy → `true` (no response written). Else writes **401** `{"error": "<what> requires a <Dhan|Zerodha> session. Connect <Dhan|Zerodha>.", "broker": "<zerodha|dhan>", "problems": health.problems}` where the label is `"Dhan"` iff `activeBroker==="dhan"` else `"Zerodha"`, and returns `false`. Callers use the string `what`: `"Historical data"` (history, spread-history, intraday, minute, fivemin), `"Option chain"`, `"Taking a trade"`, `"Closing a trade"`.
### D1.2 `zerodhaCaptureAllowed(what)` (:200-215) — gate of every NIFTY recorder
`activeBroker !== "zerodha"` → one-time (`zerodhaOnlyCaptureWarned`, never reset for the process lifetime) `console.log` + `false`. Else `kite.getAccessToken() !== null`. Used by `captureOptionOi` (:3627), `backfillPrevClose` (:3811), and (to verify in §D16) the futures capture/backfill and `backfillOiFrames`. **Consequence: with Dhan active no OI frame / snapshot / prev-close is captured; their endpoints keep serving whatever is in memory (empty on a fresh process).**
### D1.3 `sendError(res, err)` (:3347-3366)
`err instanceof KiteError` → if `status` is 401 or 403: `kite.clearSession()` + fire-and-forget `clearKiteSession()` (Mongo, warn on failure); then `res.status(err.status).json({error: err.message})`. Otherwise **500** `{error: err.message}` (non-Error → `"Unknown error"`). Non-Kite errors never touch the session. Note `KiteError.status` can be `0 → 500` (`res.status || 500` at throw sites).
### D1.4 IST/time helpers (exact)
- `IST_OFFSET_MS = 5.5*60*60*1000 = 19_800_000` (:3421). All IST work is fixed-offset arithmetic; **no `Intl`, no TZ database, no DST** ⇒ Go: `time.UnixMilli(t).UTC().Add(5h30m)` (never `time.LoadLocation` + wall clock arithmetic across DST-less zone is fine but unnecessary).
- `istDayKey(at=Date.now())` (:1699): `new Date(at+19_800_000).toISOString().slice(0,10)` → `"YYYY-MM-DD"` (UTC calendar date of the shifted instant). `toISOString` throws `RangeError` for NaN/out-of-range `at` (not reachable from internal callers).
- `istDateTime(d)` (:1705): `new Date(d.getTime()+19_800_000).toISOString().slice(0,19).replace("T"," ")` → `"YYYY-MM-DD HH:MM:SS"` IST wall time (what Kite historical accepts as `from`/`to`).
- `isMarketOpen()` (:1711): shifted `getUTCDay()` ∉ {0,6} and `mins = h*60+m` (seconds ignored) in **[555, 940]** inclusive = 09:15:00 … **15:40:59** IST. No `EXTRA_SESSION_DAYS`, no holidays. Gates `POST /api/trades` and Synthetic/Box.
- `isIstMarketHours()` (:3527-3532): weekend rejected **unless** `EXTRA_SESSION_DAYS.has(istDayKey())`; then `mins` in **[550, 945]** inclusive = 09:10:00 … **15:45:59** IST. Gates the capture tick and the 30-min backfill timer. `EXTRA_SESSION_DAYS` (:3512) = `new Set((env.EXTRA_SESSION_DAYS ?? "").split(",").map(trim).filter(Boolean))` — read once at module load, **not validated** (any string accepted, compared with exact `"YYYY-MM-DD"` equality).
- **Holidays**: there is NO holiday calendar in `index.ts`; mid-week exchange holidays pass `isIstMarketHours()`. They are detected after the fact by `isQuoteFromToday(stamp)` (:3551-3557): `null` if stamp empty/undefined; `day = stamp.slice(0,10)`; `null` if `!/^\d{4}-\d{2}-\d{2}$/.test(day)`; else `day === istDayKey()`. Callers treat only `=== false` as "holiday", `null` fails **open** (capture proceeds). The stamp is the spot's `last_trade_time ?? exchange_timestamp ?? ""` string from Kite `/quote` (kite.ts getQuoteFull) — Kite sends `"YYYY-MM-DD HH:MM:SS"` (IST wall time), so a plain `slice(0,10)` string compare against the IST date key is valid; Go must not parse it with a timezone. `noteMarketClosed` (:3559-3570) logs once per IST day (`closedDayLogged`). The `internal/calendar` package in the Go repo is **not** consulted by this code; do not add it (it would change which minutes are captured).
- `istTimeOnDayMs(t, minutesOfDay)` (:3424): `Date.UTC(y,m,d of (t+IST_OFFSET)) + minutesOfDay*60000 - IST_OFFSET`. `sessionOpenMs` = minute 555; `sessionCloseMs` = minute 940 (15:40; comment: SEBI extension effective 2026-08-03 but **not date-gated** here, unlike `hourlyCapture.marketHoursFor`).
- `isPreOpenBucket(bEnd)` (:3460): `bEnd <= sessionOpenMs(bEnd)` (a bucket ending exactly 09:15:00 is pre-open and dropped; the first kept 1m bucket ends 09:16:00, 5m ends 09:20, 15m 09:30, 1h 10:15?? — no: see `bucketEndMs`: 1h buckets are IST-hour aligned so the first 1h bucket ends **10:00** and contains 09:15-10:00).
- `bucketEndMs(t, bsize)` (:3480-3487), `bsize` in ms: `close = sessionCloseMs(t)`; `t >= close → close`; else `min(Math.ceil((t+19_800_000)/bsize)*bsize - 19_800_000, close)`. A sample exactly on a boundary belongs to the bucket **ending** at it (ceil). Integer ceil-div is exact in Go (verified reasoning: ms values < 2^41, bsize ≥ 60000 ⇒ the f64 quotient never rounds up across an integer for a non-multiple). Boundaries are IST-calendar aligned: 1h boundaries land on IST :00 (epoch alignment would give :30). For `t` after 15:40:00 on the same IST day all buckets collapse to **15:40**.
- `candleEndMs(candleStart, bsize) = bucketEndMs(candleStart + 60000, bsize)` (:3498): a Kite candle is stamped with its START, so the candle labelled 09:20 closes at 09:21 and belongs to the bucket ending 09:25 (5m).
- `delay(ms)` (:1720) = `setTimeout` promise; `makeIdResolver(all)` (:1725) = `Map<instrument_token, "EXCHANGE:TRADINGSYMBOL">`, **last duplicate token wins**, unknown → `null`.
- JS-to-Go traps in this group: (1) `istDayKey` uses UTC date of the shifted instant — a request at 00:10 IST gets *today's* IST key, but code using `toISOString().slice(0,10)` **without** the shift (chart `fmtDate`, §D4) gets the *previous* date until 05:30 IST; (2) `Date#getMonth/setMonth/getDate/setDate/setFullYear` use the **server's local TZ** (chart routes, §D4); production TZ unknown ⇒ pin `TZ` or replicate with UTC; (3) `new Date(y, m, d)` style rollover (e.g. `setMonth(getMonth()-3)` on May 31 → Feb 31 → Mar 3) must be replicated with Go `AddDate` (same normalisation).


*Erratum to §D1.4 (`isPreOpenBucket` bullet, written confusingly above): first KEPT bucket end after 09:15 is **1m 09:16, 5m 09:20, 15m 09:30, 1h 10:00**; a sample taken 09:10-09:15:00 maps to the bucket ending ≤ 09:15 and is dropped on both live and backfill paths.*

### D2.2 `deriveFnoBoard(all)` (:3237-3299) → `BoardItem[]` (shape `{symbol,name,spot_token,futures:[{token,expiry,lot_size}],is_index?:true}`)
1. Single pass over `all` in dump order, branches **in this order** (an instrument takes the first matching branch only):
   a. `exchange==="NFO" && instrument_type==="FUT" && name` (non-empty) → push into `futuresByUnderlying[name]` (Map, insertion order = first-seen underlying in the dump).
   b. else `segment==="INDICES"` → `indexBySymbol[tradingsymbol]` (last duplicate wins). Checked before the equity branch because indices may carry `instrument_type "EQ"`.
   c. else `exchange==="NSE" && instrument_type==="EQ"` → `eqBySymbol[tradingsymbol]` (last duplicate wins).
   (FUT rows with empty `name` fall through to b/c and are ignored.)
2. For each `[symbol, futs]` in Map order: `futures = futs.sort((a,b)=>a.expiry.localeCompare(b.expiry)).slice(0,3).map({token: instrument_token, expiry, lot_size})`. The sort is **stable** and in-place on the grouped array; equal expiries keep dump order; **no filter on expiry ≥ today** (an expired contract still present in the dump is `futures[0]`).
3. `eq = eqBySymbol.get(symbol)`: found → `stocks.push({symbol, name: eq.name, spot_token: eq.instrument_token, futures})` (no `is_index` key); else `resolveIndexSpotSymbol(symbol, sym=>indexBySymbol.has(sym))` (indexSpot.ts: candidates `[INDEX_SPOT_MAP[symbol], symbol]` deduped, **curated Zerodha name first**) → `idx` found → `indices.push({symbol, name: idx.tradingsymbol, spot_token: idx.instrument_token, futures, is_index: true})` (`name` is the *tradingsymbol* e.g. `"NIFTY 50"` Zerodha / `"NIFTY"` Dhan); otherwise the underlying is **silently skipped**.
4. `stocks.sort(symbol.localeCompare)`, `indices.sort(...)`; result `[...indices, ...stocks]`.
- Sort-order trap: `localeCompare` is ICU root collation (Node 22, ICU 78.2, locale en-US). Probe (node -e, 38 real F&O-style symbols incl. `M&M`, `M&MFIN`, `BAJAJ-AUTO`, `MCDOWELL-N`, `NAM-INDIA`, `360ONE`, `NIFTYNXT50`) gave **identical order to byte comparison** for upper-case alphanumerics, but punctuation ordering differs: ICU `_ < 1 < a < A < "A B" < A_B < A-B < A.B < A&B < AB` whereas bytes give `space < & < - < . < digits < letters < _`. Real symbols only differ if two symbols diverge at a punctuation char vs a letter/other punctuation; use `golang.org/x/text/collate` (language.Und/English) for exact parity, or byte order with a fixture over the live dump. Expiry strings are ASCII digits+`-` ⇒ byte order is exact.
- `diagnoseBoard` (`brokers/boardDiagnostics.ts:62-155`) deliberately mirrors the same three-way partition (it adds `unmatchedUnderlyings` with `reason: indexSpotMap[underlying] ? "no_index_mapping" : "no_spot_equity"`, `empty_underlying` sample ≤10, `unmatchedSamples` capped 30). `checkKnownSymbols` (:157-193) defaults `["BHEL","RELIANCE","HDFCBANK","SBIN","TCS","INFY","ICICIBANK","AXISBANK","BHARTIARTL"]`; its `onBoard = futures>0 && equity && validExpiries>0 && validLotSizes>0` is **stricter than `deriveFnoBoard`** (which checks neither). Served by `brokers/routes.ts:269` (api.md §2.9) — diagnostics only, no persistence.

## D3. Risk-free rate (`adminRfRate`, `app_settings`)

- Persistence (`db.ts:810-851`): collection **`app_settings`** (`AppSetting`, default Mongo connection, schema `{_id: String, value: Number required, updated_at: Date default now}`); single document `_id:"rf_rate"`; `saveRfRate`: no-op if `!isDbEnabled()` (`mongoose.connection.readyState===1`), else `updateOne({_id:"rf_rate"},{$set:{value: rf, updated_at: new Date()}},{upsert:true})`; `loadRfRate`: `findById("rf_rate").lean()` → `value` or `null` (DB disabled → `null`). ## D4. Chart / history endpoints and dividends
All six chart routes share: `requireMarketData(res,"Historical data")` **before** anything else (401 as §D1.1; also for symbols that would 404), `symbol = String(req.params.symbol).toUpperCase()`, board lookup `deriveFnoBoard(all).find(b => b.symbol.toUpperCase()===symbol)` → 404 `{"error":"No F&O instrument found for \"<SYM>\"."}`, failures `sendError`. Data comes from `history` = `HistoryProvider` for the **active** broker (brokers.md §4.6). Caches are plain `Map`s keyed by upper-case symbol only (**not** keyed by broker/generation, **unbounded**, never evicted except by overwrite; a broker switch can serve the other broker's cached payload until the IST day rolls). In Go use `RWMutex`+map (or sync.Map) and store the final JSON bytes.
Common JS traps: `fmtDate = d => d.toISOString().slice(0,10)` is the **UTC** date (before 05:30 IST it is yesterday's IST date); `from.setDate(getDate()-7)` / `setMonth(getMonth()-3)` / `setFullYear(getFullYear()-2)` act on the **server-local** calendar (identical to "−7×24 h" only when the zone has no DST; month/year rollover as in §D1.4).
- **`GET /api/history/:symbol`** (:1733-1787): cache `historyCache` `{day: istDayKey(), data}` valid while `day === istDayKey()` (checked **before** the instrument load and after the 401 check). `to=new Date()`, `from=to` with `setMonth(getMonth()-3)`; for each board future (≤3, board order) **sequentially** `history.getHistoricalOi(token, fmt(from), fmt(to))` (Kite: `GET /instruments/historical/{token}/day?from=..&to=..&oi=1`, candle → `{date: ts.slice(0,10), close: Number(c[4]??0), oi: Number(c[6]??0)}`, priority `interactive`). Response `{symbol: item.symbol, name: item.name, is_index: !!item.is_index, futures:[{token, expiry, points:[{date, oi, close}]}]}` — note key order `date, oi, close` in output vs `date, close, oi` in the provider.
- **`GET /api/spread-history/:symbol`** (:1791-1884): cache `spreadHistoryCache` per IST day. `fromDate=now.setFullYear(−2)`; per future i (`if (i>0) await delay(200)`) `history.getHistorical(token, from, to, "day")` → `{t, close}`; `map[t.slice(0,10)] = close` (later duplicate date overwrites). Pair loop `p=0..n-2`: iterate `nextMap` in insertion order; if `currentMap` has the date **and `spreadMap` lacks it** → `spreadMap[date] = nextClose - currentClose` (earlier pair has priority; unrounded). `points = entries sorted by date.localeCompare` → `{date, spread: Math.round(spread*100)/100}` (JS `Math.round` = round-half-up toward +∞: `-1.005*100=-100.49999…`→`-100`; **`Math.round(-0.5)=-0`**, so negative ties round toward +∞; `-0` serialises as `0`). Stats over the **rounded** points: `sum += spread`; `max`/`min` by strict `>`/`<`; `count=len`; `mean = count>0 ? Math.round((sum/count)*100)/100 : 0`; `count===0 → max=min=0`. `dataRange = {from: points[0]?.date ?? fromStr, to: points[last]?.date ?? toStr}`. Response `{symbol, name, is_index, dataRange, points, stats:{mean,max,min,count}}`. With <2 futures: empty points, `mean/max/min` 0. Transport (`redis.ts`, covered in storage.md §3): Upstash REST `POST {UPSTASH_REDIS_REST_URL}/pipeline`, `Authorization: Bearer <UPSTASH_REDIS_REST_TOKEN>`, body = JSON array of commands, 8 s `AbortController` timeout, ≥3 consecutive failures ⇒ `COOLDOWN_MS` = 60 s mute (`canSend()` false), body chunked ≤ 800 000 bytes (chunk failure ⇒ whole call returns `null`), per-command `{error}` ⇒ that result `null` (+ warn). All keys carry `KEY_PREFIX = "calspread:"`. Disabled (`UPSTASH_REDIS_REST_URL/TOKEN` unset) ⇒ every helper is a no-op and the caches are memory-only (the Go/PG port replaces this layer; the env vars disappear).
- **Keys written by this file** (hash field = bucket-end epoch ms as decimal string; value = `JSON.stringify(point)`): `oiframe:v2:{1m,5m,15m,1h}` (`OiAggPoint`), `futoiframe:{1m,5m,15m,1h}` (`FutOiPoint`), `futcontracts` (whole-key JSON array of `FutContract`, `SET … EX`), `prevclose` (whole-key JSON `OptionPrevClose`), `chainsnap:min:{IST day}` and `chainsnap:hour:{IST day}` (`ChainSnapshot`, `tokens` = `{"<token>":[oi,ltp]}`). The `v2` in `oiframe:v2:*` records the meaning change "window pinned per session" (`:519-546`): v1 keys are never read; they age out by TTL.
- **TTLs** (`frameTtlSec` = `floor((retentionMs + 86_400_000)/1000)`): `oiframe:v2:1m` / `futoiframe:1m` **172 800**; `5m` **345 600**; `15m`,`1h` **691 200**; `chainsnap:min:*` **172 800**; `chainsnap:hour:*` **432 000** (4 d + 1 d); `prevclose` **172 800**; `futcontracts` **691 200** (`maxFrameRetentionMs`+slack; refreshed only when the contract set changes).
- Buffer: `pendingHashWrites: Map<key,{entries: Map<field,value>, stale: Set<field>, ttlSec, maxFields}>` and `pendingPlainWrites: Map<key,{value,ttlSec}>`. `queueHashField(key,field,value,ttlSec,maxFields=3000)` (no-op if Redis disabled): updates `ttlSec/maxFields`, `stale.delete(field)`, `entries.set(field, value)` — the **object reference is stored and serialised at flush time** (later in-place edits of the same point before the flush are what gets written). `queueHashDrop(key, fields, ttl)` (empty list ⇒ no-op): `entries.delete(f); stale.add(f)`. `queuePlainWrite` overwrites by key. Caps: `MAX_BUFFERED_FRAME_FIELDS = 3000`, `MAX_BUFFERED_SNAPSHOT_FIELDS = 60` (snapshot keys pass 60).
- `flushRedisWrites()` (:631-698) in order: Redis disabled ⇒ return; `flushInFlight` ⇒ `flushAgain = true`, return; nothing pending ⇒ return; `!canSend()` ⇒ return (leave buffered); else `flushInFlight=true; flushAgain=false`, **detach** both pending maps (new empty maps), build commands per hash `hashWriteCommands(key, entries, [...stale], withTtl ? ttlSec : undefined)` with `withTtl = now - (ttlRefreshedAt.get(key) ?? 0) > TTL_REFRESH_EVERY_MS (900 000)` ⇒ `["HSET", key, f1, json1, f2, json2, …]` (single command if any entries), `["HDEL", key, …stale]` (if any), `["EXPIRE", key, ttl]` (only if `withTtl` and at least one command); plains ⇒ `["SET", key, json, "EX", ttl]`. `pipeline(cmds)`: `null` ⇒ `requeueFailedWrites`; success ⇒ `ttlRefreshedAt.set(key, now)` for keys that carried EXPIRE (stamped only after observed success); exception ⇒ requeue + `[Redis] flush failed:`; `finally`: `flushInFlight=false`; `flushAgain` ⇒ immediate `void flushRedisWrites()`.
- `requeueFailedWrites(hashes, plains)` (:712-745): per key: no current ⇒ put the old batch back as-is; else for each old entry add it **only if** current has neither an entry nor a stale mark for that field; for each old stale add it only if current has no entry for it. Plains: re-add only if no newer value. Then the backlog cap per key: `over = entries.size - maxFields`; if `over > 0` drop the `over` **numerically-smallest** field names (oldest bucket) and `console.warn("[Redis] <key>: dropped N buffered buckets …")`.
- `startRedisFlushRetry()` (:703): only when Redis enabled; `trackInterval("redis-flush-retry", setInterval(flush-if-pending, 60_000))`, **not market-hours gated** (rescues the 15:40 closing buckets after an outage).
- Flush triggers: end of every capture minute (`startOptionOiCapture` tick), end of each backfill chain (cold start, 30-min timer, post-login), `persistPrevClose()` (immediately), the 60 s retry timer.
- Read side (`redis.ts`): `HGETALL` (accepts both flat-array and object replies; values `JSON.parse`d, unparsable values silently dropped; unreachable ⇒ empty map, indistinguishable from "no data"), `GET`+`JSON.parse`, `PING` (must reply `PONG`).
- **What PG must preserve**: (a) per-(key,field) idempotent upsert (a re-written bucket replaces, never duplicates); (b) closed-bucket-only persistence (`p.t <= t` rule, §D13) so a forming bucket never survives a restart; (c) retention pruning at write time (HDEL ⇔ DELETE of pruned buckets) plus an expiry for abandoned per-day keys; (d) warm-load merge rule "existing in-memory wins" (§D17); (e) the write path must never block or fail a capture tick (best-effort, errors logged).

## D13. Option-OI frames: config, bucket rules, strike window, aggregation, retention, forming/partial buckets
### D13.1 Frame table (`OI_FRAMES` :363-376; `OI_FRAME_KEYS` order `["1m","5m","15m","1h"]` via `Object.keys`)
| key | `intervalMin` | `retentionMs` | `kiteInterval` (unused by frames code) | Redis TTL s | buckets per full session (ends) |
|---|---|---|---|---|---|
| `1m` | 1 | 86 400 000 (1 d) | `minute` | 172 800 | 385: 09:16 … 15:40 |
| `5m` | 5 | 259 200 000 (3 d) | `5minute` | 345 600 | 77: 09:20 … 15:35, 15:40 |
| `15m` | 15 | 604 800 000 (7 d) | `15minute` | 691 200 | 26: 09:30 … 15:30, 15:40 |
| `1h` | 60 | 604 800 000 (7 d) | `60minute` | 691 200 | 7: 10:00 … 15:00, 15:40 |
Retention is pruned against **calendar** time (`t - retentionMs`), not sessions (weekend inside the window shrinks it; the comment at :367-372 explains why 1h = 7 d). `parseFrameKey(raw)` (:380): `String(raw ?? "5m")`; unknown/empty/array ⇒ `"5m"`; case-sensitive. `OI_BACKFILL_BAND = 45` (:431).
### D13.2 Point shape `OiAggPoint` (:384-430) and field provenance
`{t: epoch ms of bucket END, totalCe, totalPe, straddle, spot, wLo?, wHi?, partial?: 1}` (numbers are JS doubles; OI totals are integers in practice; `straddle`/`spot` are floats, unrounded).
- **Live-created or live-updated points never contain `wLo`/`wHi`.** `currentWindowAgg` computes them (:4114-4115) but `appendOiFrameLive` copies only `totalCe,totalPe,straddle,spot,(partial)` (:4137-4156; grep-verified: `wLo/wHi` appear only at :407-408, :4114-4115, :4776-4777). They are set only by the **backfill reconstruction** (and copied by `coarsenOiFrame`'s `{...p, t}` and by Redis round-trips). Clients therefore see absent bounds on live buckets and present bounds on backfilled ones. A live same-bucket update on a point that came from a backfill/warm-load **keeps that point's old `wLo/wHi`** (only totals/straddle/spot are overwritten) even though the new totals are summed over the session's (possibly different) window. Port as-is (it is observable behaviour).
- Key order: live-created `t,totalCe,totalPe,straddle,spot[,partial]`; backfilled/coarsened `t,totalCe,totalPe,straddle,spot,wLo,wHi[,partial]` (spread `{...p, t}` keeps the original order); a later live update that sets `partial` appends it at the end (`delete` removes it).
### D13.3 Strike window (pinned per session) — constants `WINDOW_DOWN = 26`, `WINDOW_UP = 24` (:3975-3976)
- `nearestStrikeIndex(strikes, spot)` (:3985): linear scan, `best=0, bestD=Infinity`, update on strictly smaller `|strike-spot|` ⇒ **lowest strike wins ties**; NaN spot ⇒ index 0.
- `pinStrikeWindow(strikes, spot)` (:4017): `null` if no strikes or `!(spot > 0)`; `atm = nearest`; `{lo: strikes[max(0, atm-26)], hi: strikes[min(n-1, atm+24)]}` — **strike values**, inclusive (`inWindow`: `strike >= lo && strike <= hi`).
- Pinned once per `OptionOiDay` on the first reading where `spot > 0` (`store.window`, logged `[OptionOI] <day> <expiry>: totals window pinned to strikes lo–hi (first spot S).`, note the en dash). Reset only when `optionOiDay` is replaced (new IST day or expiry change). Backfill pins its own window **per IST day from that day's first minute with spot>0** (`dayWindows`, :4715), independent of the live one.
- `frameLadder(meta)` (:4032): `ceByStrike`/`peByStrike` (last duplicate strike wins), `strikes` = ascending unique numbers.
### D13.4 `currentWindowAgg(store, unseeded)` (:4063-4126) — exact aggregation
Returns `null` if `spot` array empty, last spot ltp `!(> 0)`, or no strikes. Pins the window if absent (return `null` if it cannot). `atmIdx = nearestStrikeIndex(strikes, spot)` over the **whole ladder**. For each strike (ascending) in the window: `totalCe += lastOf(ce).oi`, `totalPe += lastOf(pe).oi` where `lastOf(tok)` = last series sample `{oi, ltp}` or zeros; `missing++` if the CE or PE token ∈ `unseeded`. `straddle = ceAtm > 0 && peAtm > 0 ? ceAtm + peAtm : 0` using the last `ltp` of the **live-ATM** strike's CE and PE (follows spot, unlike the totals). Result `{t: Date.now() /*ignored by the append*/, totalCe, totalPe, straddle, spot, wLo, wHi, partial: 1 iff missing>0}`. `partial` means "a token inside the window had no reading at all this cycle" (**not** `oi===0`).
### D13.5 `appendOiFrameLive(t, agg)` (:4128-4185) — for each of the four frames (order 1m,5m,15m,1h)
1. `bEnd = bucketEndMs(t, intervalMin*60000)`; `isPreOpenBucket(bEnd)` ⇒ skip this frame entirely (the day cache and chain snapshots still recorded the sample).
2. `last = points.at(-1)`; `last && last.t === bEnd` ⇒ mutate in place: `totalCe,totalPe,straddle,spot` ← agg; `agg.partial ? last.partial = 1 : delete last.partial`. Else `points.push({t: bEnd, totalCe, totalPe, straddle, spot[, partial: 1]})`. Only the **tail** is compared (a live sample for an older bucket than the tail would be appended out of order — cannot occur live).
3. Retention: `cutoff = t - retentionMs`; `while points[0].t < cutoff: dropped.push(points.shift().t)`.
4. Redis: for `p` in `points.slice(-2)`: `if (p.t <= t) queueHashField("oiframe:v2:"+key, p.t, p, ttl)` — **only buckets whose end ≤ the sample time (closed ones) are persisted**, the forming bucket never; `queueHashDrop(rk, dropped, ttl)`.
Effect: the newest point is the *forming* bucket (end > now) until its boundary passes; the value is the latest sample inside it ("closing state so far").
### D13.6 Serving: `completedBuckets(points)` (:443) and `GET /api/option-oi-frame/:underlying` (:2334)
`now = Date.now()`; `end = points.length; while (end>0 && points[end-1].t > now) end--;` (strict `>`: a bucket whose end equals `now` is served) ⇒ returns the **same array** if nothing trimmed else a slice (Go: copy under lock before encoding). Response `200 {"frame": key, "intervalMin": n, "retentionMs": n, "points": OiAggPoint[]}` (ascending `t`). Public; unknown frame ⇒ `5m`; `:underlying` ignored. Empty store ⇒ `points: []`.
### D13.7 Merge of backfilled points: `downsampleAgg` + `mergeOiFrame` (:4187-4249)
- `downsampleAgg(points, intervalMin)`: per point `bEnd = candleEndMs(p.t, bsize)` (candle START shifted by +1 min, §D1.4); skip pre-open; `byBucket.set(bEnd, {...p, t: bEnd})` (**last candle in the bucket wins, including its `wLo/wHi/partial`**; a partial earlier minute does not mark the bucket); sorted by `t`.
- `mergeOiFrame(key, backfilled)`: `byBucket` = existing points keyed by `t`; for each downsampled `p`: set iff `!cur || (cur.partial && !p.partial)` (**a live/trusted bucket is never overwritten; a `partial` one yields to a complete one**; a partial one is NOT replaced by another partial one). Then `points = sorted(values).filter(t >= now - retentionMs)`; `persistWholeFrame(rk, points, before, ttl, now)` (§D14).
### D13.8 Constants summary for §F
`WINDOW_DOWN 26`, `WINDOW_UP 24`, `OI_BACKFILL_BAND 45`, `PREV_CLOSE_BAND 60`, `CAPTURE_LEAD_MS 3000`, `OPTION_OI_INTERVAL_MS 60000`, pre-open capture from 09:10 (`isIstMarketHours`), session open 09:15, close 15:40, last capture minute 15:45.

## D14. Coarsening (no Kite calls) and whole-frame persistence (:4251-4465)
- `coarsenSourceFor(key)` (:4251): among the other frames with `intervalMin < ours`, `ours % theirs === 0`, `theirs.retentionMs >= ours.retentionMs`, pick the one with the **largest** `intervalMin`. Result: `5m ← 1m`? No — `1m` retention (1 d) < `5m` (3 d), so `5m` has **no** source (null); `15m ← 5m`? `5m` retention 3 d < 7 d ⇒ no; `15m` has **no** source; `1h ← 15m` (15 ∣ 60, 7 d ≥ 7 d, coarser than `5m`/`1m`). Thus **only `1h` is ever coarsened, from `15m`** (computed, not hard-coded; keep it computed).
- `collapseToBuckets(points, bsize, now)` (:4287): for each source point `bEnd = bucketEndMs(p.t, bsize)`; skip pre-open; skip `bEnd > now`; **skip unless `p.t === bEnd`** (only the point that *closes* the coarse bucket qualifies); `Map.set(bEnd, p)` (later wins).
- `coarsenOiFrame(key, src, now)` (:4343): `collapsed` empty ⇒ 0; `cutoff = now - retention`; for `[bEnd, p]`: skip `p.partial`; skip `bEnd < cutoff`; `cur = existing`; skip if `cur && !cur.partial`; else `set(bEnd, {...p, t: bEnd})`, `filled++`. `filled===0` ⇒ return 0 (no write). Else rebuild `points = sorted(filter(t>=cutoff))` and `persistWholeFrame`. Returns `filled`.
- `coarsenFutOiFrame` (:4393): same but no `partial` concept: skip `bEnd < cutoff`, skip existing; `cloneFutOiPoint({t: bEnd, legs: p.legs})`.
- `coarsenFrames()` (:4436): ONE `now = Date.now()` for every frame and both families; for each key with a source: `opt = coarsenOiFrame`, `fut = coarsenFutOiFrame`; if either > 0 log `[OptionOI] Derived <opt> option and <fut> futures <key> bucket(s) from the <src> frame (no Kite calls).` Pure in-memory + buffered writes; idempotent. Call sites: end of `warmLoadFromRedis` (outside its try/catch), end of each backfill chain (cold start, 30-min timer, post-login).
- `persistWholeFrame(rk, points, before, ttl, now)` (:4316): `kept` = all current `t`; `queueHashField(rk, t, p, ttl)` for **closed** points only (`p.t <= now`); `queueHashDrop` for `before \ kept` (a forming bucket counts as kept so its HDEL never fires). Default maxFields 3000.

## D15. Gap-aware backfill of the option frames (`backfillOiFrames`, :4586-4800) and its detectors
### D15.1 Window detectors (pure given store contents + clock + two rate-limit maps)
- `oiBackfillFromMs(now)` (:4467): `from = now`; for each frame in key order: `retentionStart = now - retentionMs`; empty ⇒ `from = min(from, retentionStart)`; else `need = max(retentionStart, newest.t)`; `headNeed = missingHeadMs("opt", oldest.t, cfg, retentionStart)` ⇒ `need = min(need, headNeed)`; `partialNeed = partialRepairFromMs(points, cfg, retentionStart)` ⇒ `need = min(need, partialNeed)`; `from = min(from, need)`.
- `missingHeadMs(family, oldest, cfg, retentionStart)` (:4547): `open = sessionOpenMs(oldest)` (09:15 IST of the oldest point's day); `oldest <= open + intervalMin*60000` ⇒ `null`; `open < retentionStart` ⇒ `null`; `key = "<family>:<intervalMin>:<istDayKey(open)>"` in `headRepairs: Map<key,{n,at}>`; seen: `n >= HEAD_REPAIR_MAX_ATTEMPTS (4)` ⇒ `null`; `now - at < HEAD_REPAIR_MIN_GAP_MS (25 min)` ⇒ return `open` **without** spending an attempt; else `n+1, at=now`; unseen ⇒ `{n:1, at:now}` + log `[OptionOI] <family> <i>m frame is missing the head of <day> (oldest point <ISO>) — backfilling from the open.`; returns `open`.
- `partialRepairFromMs(pts, cfg, retentionStart)` (:4504): `oldest = first point with partial` (ascending) else `null`; `from = max(retentionStart, oldest.t - intervalMin*60000)`; `key = "<intervalMin>:<istDayKey(oldest.t)>"` in `partialRepairs`; same state machine with `PARTIAL_REPAIR_MAX_ATTEMPTS = 3` and the same 25-min gap; first sighting logs `[OptionOI] <i>m frame has an incomplete bucket at <ISO> — reconstructing it again from Kite.`
- Both maps are process-lifetime, unbounded, and mutate **while computing the window** (several callers per cycle ⇒ the 25-min gap rule). Callers snapshot the window **before** capturing (a live capture stamps every frame at `now` and would collapse the gap): `triggerPostLoginBackfill` (:3401-3402), the 30-min timer, cold start.
### D15.2 `backfillOiFrames(fromMsOverride?)`
Preconditions/guards: `oiBackfillRunning` single-flight (`finally` resets) and `zerodhaCaptureAllowed`; `fromMs = override ?? oiBackfillFromMs(now)`; `now - fromMs < 90_000` ⇒ return (essentially current). `sel = niftyNearestExpiryOptions(all)` (**current** nearest expiry only: periods before those contracts were listed cannot be rebuilt); `strikes` empty ⇒ return. `fromStr/toStr = istDateTime(fromMs/now)`.
1. Spot minute candles: `history.getHistorical(spotToken, fromStr, toStr, "minute", "background")` → `{t, close}` (Kite `GET /instruments/historical/{token}/minute?from=…&to=…`, `t` like `2026-10-27T09:15:00+0530`). Empty ⇒ return (no error). `minuteKey(t) = t.slice(0,16)`; `spotByMin[minuteKey] = close` and `tsByMin[minuteKey] = original t` (last duplicate wins).
2. Band: `lastSpot = last candle close` → `atmNow` (strict-`<` nearest) → fetch tokens for strikes `[max(0, atm-45) … min(n-1, atm+45)]` ascending, **CE then PE per strike**, each via `fetchTok` (skipped if already fetched): `history.getHistoricalOiSeries(tok, fromStr, toStr, "minute", "background")`; on throw: `delay(1200)` + **one retry**; second failure ⇒ `unfetched.add(tok)` + `console.warn("[OptionOI] backfill: no history for token T (msg) — affected buckets stay partial.")`; empty maps stored regardless (`oiByToken.set(tok, …)`). `delay(220)` after every token (inside `fetchTok`, also after failures). ≈ 182 calls ⇒ ~65-75 s given the 350 ms gate.
3. Walk `sortedMins = keys(spotByMin).sort()` (default UTF-16 order ⇒ chronological for `YYYY-MM-DDTHH:MM`). For each minute `mk`: skip `!(spot > 0)`; `dayKey = mk.slice(0,10)`; pin the day's window from the **first minute of that day in this run** (`dayWindows`; if `pinStrikeWindow` null ⇒ `continue`); `atmIdx = nearestStrikeIndex(strikes, spot)`; for every strike in the window: `totalCe += sumOi(ce)` where `sumOi` updates `lastOi[tok]` when the minute has a value else carries forward (0 if never seen); `missing++` if `unknownTok(ce)||unknownTok(pe)` (= token has no entry in `oiByToken` — drifted out of the fetched band — or is in `unfetched`); `straddle` from `closeOf` (candle **close** as LTP proxy, carried forward) of the ATM CE/PE: `ceAtm > 0 && peAtm > 0 ? sum : 0`. `t = new Date(tsByMin.get(mk) ?? mk+":00").getTime()` (the `+0530` offset form is parsed by V8's legacy parser; the fallback branch is unreachable because `tsByMin` has every `mk`; if reached it would parse as **server-local** time) — Go: parse with layout `2006-01-02T15:04:05-0700`. Point `{t (candle START ms), totalCe, totalPe, straddle, spot, wLo, wHi[, partial: 1]}` pushed (finite `t` only).
4. `for key of OI_FRAME_KEYS: mergeOiFrame(key, perMinute)` (the same array for all four frames; `downsampleAgg` copies). Log `[OptionOI] Backfilled frames from <fromStr> (<n> minutes reconstructed[, <k> partial — <u> token(s) unavailable, will retry]).`; any exception ⇒ `[OptionOI] frame backfill failed: <msg>` (swallowed).
Traps: (i) backfill totals use the **candle CLOSE OI of each minute** vs live uses the **/quote oi at sample time**; (ii) `partial` is computed per minute but a bucket takes the *last* minute's flag; (iii) multi-day windows pin each day separately from the day's first available minute and the band is centred on the **last** spot of the range ⇒ early days can reach outside it ⇒ partial; (iv) LTP proxy = candle close, so backfilled `straddle` ≠ live `straddle` (live uses `last_price`).

## D17. Scheduler, startup order, warm load, post-login trigger, shutdown
### D17.1 Capture scheduler `startOptionOiCapture()` (:5120-5187) — "what runs each minute"
- Called once at boot (after `warmLoadFromRedis()` and `startRedisFlushRetry()`; see D17.3). First it snapshots `coldOptFrom = oiBackfillFromMs(now)` and `coldFutFrom = futOiBackfillFromMs(now)` **before** the first tick.
- `tick()`: `if (isIstMarketHours())` (Mon-Fri **or** `EXTRA_SESSION_DAYS`, 09:10:00-15:45:59 IST, no holiday list) ⇒ fire-and-forget async chain `captureOptionOi()` → `captureFuturesOi()` → `flushRedisWrites()` (sequential; the Kite quote budget is ~1 req/s). Then `scheduleNextTick()` regardless. `tick()` is also called **once immediately** at boot.
- `scheduleNextTick()`: `now = Date.now(); target = Math.ceil((now + 3000) / 60000) * 60000 - 3000; if (target - now < 1000) target += 60000; setTimeout(tick, target - now)`. ⇒ ticks land at **hh:mm:57** (3 s before each minute boundary, so the sample represents the bucket that ends at the boundary); a tick firing within 1 s of the target re-arms for the following minute. The `setTimeout` chain is **not** registered with `trackInterval`, so shutdown's `clearTrackedIntervals()` does not stop it. Go: `time.Timer` re-armed from the wall clock each cycle (no fixed ticker ⇒ no drift), stop on shutdown.
- Cold-start chain (not market-hours gated; each step self-gates on `zerodhaCaptureAllowed`): `backfillOiFrames(coldOptFrom)` → `backfillFutOiFrames(coldFutFrom)` → `backfillPrevClose()` → `coarsenFrames()` → `flushRedisWrites()`.
- `trackInterval("option-oi-capture", setInterval(…, 30*60*1000))` — **anchored to process start**, not the wall clock: `if (!isIstMarketHours()) return;` then `optFrom/futFrom` snapshot, then `backfillOiFrames(optFrom)` → `backfillFutOiFrames(futFrom)` → `backfillPrevClose()` (comment: for a process that started mid-session) → `coarsenFrames()` → `flushRedisWrites()`. Single-flight is per function (`oiBackfillRunning`, `futOiBackfillRunning`, `prevCloseBackfillRunning`); the capture tick is **not** excluded while these run (they interleave at `await` points; each merge/append is synchronous, so frames are never half-updated — Go needs an explicit lock, §D18).
- Retry/backoff summary: historical fetch retry = 1 retry after 1200 ms per option token (futures: none, abort); pacing `delay(220)` per fetched token on top of the Kite gate (350 ms between request starts, background priority yields to interactive, 20 s slot watchdog — kite.ts:96-192); head/partial repair attempts capped (4 / 3 per key, ≥25 min apart); prev-close attempts capped at 4 per IST day; no exponential backoff anywhere.
### D17.2 `triggerPostLoginBackfill()` (:3371-3415), called from `POST /api/session` (:1423) and `GET /callback` (:1453) after `persistKiteSession`
Fire-and-forget, in order: (1) if `hourlyBackfillDeps` ⇒ `backfillMissedHours(deps).catch(log)`; (2) if `eodBackfillDeps` ⇒ `backfillStockFutures(deps).catch(log)` and `checkAndRecomputeSummary().catch(warn)` (Part C); (3) `optFrom = oiBackfillFromMs(now)`, `futFrom = futOiBackfillFromMs(now)` **first**; then an un-caught async chain: `captureOptionOi()` → `captureFuturesOi()` → `backfillOiFrames(optFrom)` → `backfillFutOiFrames(futFrom)` → `backfillPrevClose()` → `coarsenFrames()` → `flushRedisWrites()`. The captures here are **not** gated by market hours (they run on any login, including weekends/nights — the quote's holiday stamp check then skips them on closed days; on a weekday evening they sample the closing state into the `15:40` bucket via `bucketEndMs(t ≥ close)`).
### D17.3 Boot order (`app.listen` callback, :5441-5557)
`initDb()` → `restoreSessionOnStartup()` (token valid only if `login_date === istDayKey()`) → `brokerManager.restore()` → `brokerManager.startActiveRuntime()` → admin sessions restore → `loadRfRate()` → hourly deps + `startHourlyScheduler` + `backfillMissedHours` + `startDayReviewScheduler` → **`await warmLoadFromRedis()`** → `startRedisFlushRetry()` → `startOptionOiCapture()` → `boxModule.boot()` (**DROPPED**), `syntheticModule.boot()`, `fairValueModule.boot()`. ### D17.4 `warmLoadFromRedis()` (:953-1042) and merge rules
`logRedisStatus()`; Redis disabled ⇒ return; `PING` false ⇒ warn `[Redis] PING failed — starting with empty in-memory caches.` and return. Then (try/catch — partial load tolerated, warn `[Redis] warm load failed: …`): for each frame key in order: `HGETALL oiframe:v2:<k>` ⇒ values with numeric `t` and `t >= now - retentionMs` ⇒ `mergeWarmLoaded(oiFrameStores[k], …)`; `HGETALL futoiframe:<k>` ⇒ also `Array.isArray(legs)` ⇒ `mergeWarmLoaded(futOiFrameStores[k], …)`. `GET futcontracts` ⇒ array ⇒ `futOiKnownContracts.set(c.expiry, c)` for entries with string `expiry`. `GET prevclose` ⇒ adopt iff `prev.forDay === istDayKey() && prev.tokens` (log `[Redis] Restored previous-close baseline (N tokens from <closedOn>) — no Kite backfill needed.`). `HGETALL chainsnap:min:<today>` ⇒ `t >= now - 1 d` ⇒ `mergeWarmLoadedSnaps(chainMinuteSnaps, …)`; for `d = 0..4`: `HGETALL chainsnap:hour:<istDayKey(now - d*24h)>` ⇒ `t >= now - 4 d` ⇒ `mergeWarmLoadedSnaps(chainHourSnaps, …)` (≈ 8+8+2+1+5 = 24 sequential REST calls, each up to 8 s). Log `[Redis] Warm-loaded N frame points, M minute and K hourly chain snapshots.` After (outside the try) **`coarsenFrames()`**.
- `mergeWarmLoaded(store, loaded)` (:913): `byBucket` = loaded by `t` (later duplicate wins) then **overlaid by the existing in-memory points (existing wins)**; `store.points = sorted(values)`; returns count of new `t`. `mergeWarmLoadedSnaps(list, loaded)` (:938): skip any `t` already present, else `upsertSnapshot`. (They guard against a login-time capture that ran during the multi-second load.)
- Persisted forming buckets are never loaded (never written, §D13.5). Warm-loaded points keep whatever `wLo/wHi/partial` they were stored with (so a stored `partial` bucket is still repairable by the next backfill window).

## E1. `boundedCache.ts` (97 lines) — `BoundedTtlCache<V>`
`new BoundedTtlCache({ttlMs, maxEntries, now = Date.now})`; `maxEntries = Math.max(1, opts.maxEntries)`. Internal `Map<string,{at, value}>` (insertion order = eviction order).
- `get(key)`: absent ⇒ `undefined`; `now() - at >= ttlMs` ⇒ **delete and return `undefined`** (TTL is exclusive of the boundary: age exactly `ttlMs` is expired); else `value`. **`get` does not refresh recency** (FIFO by last `set`, not LRU).
- `set(key, value)`: `delete(key)` first (moves it to the end), insert `{at: now(), value}`, then `evict()`.
- `evict()`: iterate all entries, delete those with `at <= now() - ttlMs` (expired first, O(n) per set); then while `size > maxEntries` delete `keys().next()` (oldest insertion).
- `delete(key): boolean`, `size` (counts expired-but-unswept entries), `clear()`. No timers, no locks; Go: mutex + `container/list`/ordered map; injectable clock for tests.
- Instances in scope: `marketDataRoutes.ts:70` `quotesCache` (`ttlMs 4000`, `maxEntries 256`, key `broker:generation:sortedTokens`); `fairValue/engine.ts:93-95` `independentCache` (`independent_cache_limit`/`independent_cache_ttl_ms` from FV config, Part A20) and `retainedInputs` (`maxEntries 8`, `ttlMs = surface_max_age_ms`), recreated on config change (:113-115, :143-145). ## E3. `ratelimit.ts` (52 lines) — exact algorithm
`rateLimit({windowMs, max, message?})` returns an Express middleware; **one private `Map<string, {count, resetAt}>` per call** (so each limiter instance has independent counters; the global `/api` limiter and a route limiter both count the same request).
1. Key (client IP): `fwd = String(req.headers["x-forwarded-for"] ?? undefined)?.split(",")[0]?.trim()`; `ip = fwd || req.socket.remoteAddress || "unknown"`. The **first** XFF element is trusted unconditionally (client-spoofable unless a proxy overwrites it); `trust proxy` is not enabled; IPv6-mapped remote addresses (`::ffff:a.b.c.d`) are used verbatim.
2. `now = Date.now()`; `bucket = buckets.get(ip)`; if absent or **`now > bucket.resetAt`** (strict) ⇒ new `{count: 0, resetAt: now + windowMs}`. `bucket.count++` (rejected requests also increment).
3. `bucket.count > max` ⇒ reject: header `Retry-After: String(Math.ceil((resetAt - now)/1000))` (can be `"0"` on the exact boundary ms), status **429**, JSON body `{"error": message ?? "Too many requests. Please slow down."}`, handler stops (no `next()`). No `X-RateLimit-*`/`RateLimit-*` headers on any response. Otherwise `next()`.
4. Fixed window anchored at the **first request** of each window (not aligned to wall-clock). Cleanup: `setInterval(…, windowMs)` (unref'd) deletes buckets with `now > resetAt`; stale buckets are also replaced lazily on access.
5. Instances: global `app.use("/api", rateLimit({windowMs: 60_000, max: 150}))` (:1083; matches `/api` and `/api/*` only — not `/`, `/login`, `/callback`; OPTIONS answered earlier by CORS and not counted); `/api/internal/kite-token`, `/api/kite/token`, `GET /api/rf` each `60_000/30`; `/api/admin/verify`, `/api/access/verify` each `5*60_000/10` with message `"Too many attempts. Try again in a few minutes."`; plus broker/synthetic/FV limiters listed in api.md §0.4 (Box delete limiter **DROPPED**). Order on a route: global ⇒ route limiter ⇒ handler/auth. Go: `map[string]*bucket` + `sync.Mutex`, same strict inequalities, same body/header; the limiter keys must be computed identically (first XFF element).

## E4. `shutdown.ts` (187 lines) — `ShutdownCoordinator`, `shutdownExitCode`
- `new ShutdownCoordinator({steps, timeoutMs = 12000, log = console.log, now = Date.now})`. `run(signal)` returns the **same promise** on repeated calls (logs `[shutdown] <signal> received while already shutting down — ignoring.`); `inProgress` getter.
- `execute`: logs `[shutdown] <signal> received — starting graceful shutdown of N step(s).`; runs steps **sequentially, awaiting each** (`await step.run()`), recording `completed` names on success (`[shutdown] ok: <name>`) or `failed {step, error}` on throw/reject (`[shutdown] FAILED: <name>: <msg> (continuing)`), **never skipping later steps**. The whole sequence is `Promise.race`d against a `timeoutMs` timer (not unref'd, cleared after the race). On timeout the sequence is **not cancelled** (it keeps running while the caller exits); log lists `stuck` = steps neither completed nor failed; result `{signal, completed, failed, timedOut, durationMs}`. Success logs `[shutdown] complete in <ms>ms — N ok, M failed.` (only when not timed out).
